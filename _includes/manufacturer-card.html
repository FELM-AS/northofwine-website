{% comment %} Manufacturer card (Plan.md): image, logo, name, external link (new tab), description, and an inline list of links to that manufacturer's own products -- not a separate page (Manufacturer has no detail page of its own; see planning/Plan.md's Produsenter section and the M3 roadmap decision this follows). No card-wide link, unlike the Product card -- there's nowhere for the whole card to link to. Matched to its own products by id, not name (names aren't guaranteed unique, ids are) -- and only when the manufacturer actually has an id: `nil == nil` is true in Liquid, so without this guard a manufacturer missing an id would match every *other* page lacking a `manufacturer` field too (404.html, listing pages, ...), not just fail to match zero products. Every real manufacturer has one (always set by EntrySerializer#serialize_entry), so this only matters for malformed/test input. lang on the name comes directly from the manufacturer's own `country` (the fixed enum) via _data/countries.yml (#8) -- no indirection needed here, unlike the Product card.
