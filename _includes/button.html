{% comment %} Button component (Plan.md's Strong/Subtle variants) -- a plain , optionally with an icon before or after the text. The two variants are left structurally identical for now (no class/attribute hook); visual distinction is deferred to manual styling added later. Params: href - required. Escaped -- pass a plain URL string. class - optional, any additional classes. text - link text, escaped. Required unless aria_label is given for an icon-only button. icon - optional, raw HTML for the icon (e.g. an inline SVG or entity) -- intentionally NOT escaped, unlike href/text, since it's meant to carry markup. icon_position - "left" or "right" (default "right"). Normalized (case/whitespace-insensitive); anything other than "left" renders on the right, matching the default. aria_label - optional, escaped.
